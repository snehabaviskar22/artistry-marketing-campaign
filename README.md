
# Artistry — Email Marketing Campaign

Artistry is a frontend portfolio project based on a fictional handmade art marketplace. It combines a promotional HTML email template with a responsive landing page to demonstrate an email marketing campaign.

## Features

- Responsive landing page with a featured product collection.
- Standalone HTML email template with a table-based layout.
- Product cards featuring paintings, pottery, illustrations, and home decor.
- Newsletter signup form with client-side validation.
- Responsive design and accessible navigation.
- Demo product actions and campaign links.

## Technologies Used

- HTML5
- CSS3 (Flexbox, Grid, Media Queries)
- JavaScript (Vanilla JS)
- SVG and JPEG images

## How to Run

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.
4. Open `email-template.html` to preview the email template.

## Note

This is a frontend-only educational project. The newsletter form and product actions are demonstrations and do not store personal data or process payments.

*AI tools were used to assist with frontend development.*
